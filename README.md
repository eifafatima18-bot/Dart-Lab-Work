# Dart Lab Work

Flutter and Dart lab exercises completed during my Mobile Development learning journey.

## Labs included

- **Lab 1:** Dart basics, functions, conditions, loops, classes, and strings
- **Lab 2:** Collections, null safety, OOP, mixins, exceptions, and async/await
- **Lab 3:** AppBar patterns, Drawer, BottomNavigationBar, and navigation layouts
- **Lab 4:** Pizza store navigation, a multi-stage quiz, and a pet adoption explorer

## Running the examples

Each `.dart` file is a separate example. Flutter UI files should be copied into a Flutter project's `lib/main.dart` (one example at a time) and run with Flutter. The WebView examples also require the `webview_flutter` package and the platform setup described in the package documentation.
